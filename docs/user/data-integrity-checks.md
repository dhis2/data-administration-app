# Data integrity checks { #data_admin_data_integrity_checks }

> **Note**
>
> This list might not include every check on your instance. New releases of DHIS2 add checks, and a system administrator can add custom checks to an instance. Custom checks appear in the app in the same list as the checks on this page. To add your own checks, see [Custom data integrity checks](#custom_data_integrity_checks) in the developer documentation.

This page lists the data integrity checks that come with DHIS2 in the **Data Administration** app, with the severity, a description and a recommendation for each check. To run the checks, see [Data integrity](#data_admin_data_integrity).

The checks are grouped by the tab where the app shows them, **Standard checks** or **Slow checks**, and then by section. The check names are the names that the app shows. The **Versions** column shows which of v41, v42 and v43 include the check. A check can also exist in v40 and earlier.

## Standard checks { #data_integrity_checks_standard }

The **Standard checks** tab has 93 checks in v43. Click **Run all standard checks** to run them all at once.

| Tracker entities with geometry not using SRID 4326 | Warning  | Geometry data in DHIS2 should conform to the WGS 84 coordinate system (SRID 4326). Tracker records (Tracked Entity, Enrollment, or Event) using a different spatial reference system may lead to unexpected results or errors in GIS-based features. This integrity check identifies such geometry records that do not use SRID 4326. | To correct this issue, update the SRID of the affected records to 4326 using the SQL queries below: UPDATE trackedentity SET geometry = ST_SetSRID(geometry, 4326) WHERE geometry IS NOT NULL AND ST_SRID(geometry) != 4326; UPDATE enrollment SET geometry = ST_SetSRID(geometry, 4326) WHERE geometry IS NOT NULL AND ST_SRID(geometry) != 4326; UPDATE event SET geometry = ST_SetSRID(geometry, 4326) WHERE geometry IS NOT NULL AND ST_SRID(geometry) != 4326; Make sure to back up your database and run this fix in a testing or staging environment before applying to production. | v41 to v42 |
